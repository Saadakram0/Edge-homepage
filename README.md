# 🌐 Microsoft Edge Homepage

An Edge-inspired New Tab dashboard built with HTML,CSS  and JavaScript. Works both as a hosted web application via GitHub Pages and as an unpacked Chrome/Edge extension.

![License](https://img.shields.io/badge/License-MIT-blue.svg)
![Manifest](https://img.shields.io/badge/Manifest-V3-green.svg)

---

## 🔥 Features

- **Edge-Style Layout**: Glassmorphism UI with smooth transitions and theme switching (Dark/Light).
- **Interactive Backgrounds**: Toggle between high-resolution background wallpapers or an interactive animated canvas particle network.
- **Custom Shortcuts Launcher**:
  - Click **"+"** to add shortcuts or mini web apps.
  - Turn on **Edit Mode** to remove tiles.
  - **Right-click** any tile to rename its label, URL, or emoji icon.
- **Google Search with History**: Fast search bar featuring recent query chips, single-click search execution, and search entry deletion.
- **Productivity Widgets**:
  - **To-Do List**: Quick task tracking.
  - **Scratchpad Notes**: Persistent text area saved automatically in `localStorage`.
- **Usage Tracker**: Real-time counter measuring time spent on your new tab page today and overall.
